영어 단어 시험지 만들기

단어를 붙여넣고 유형과 문제 수를 고르면 인쇄용 시험지와 답안지가 만들어져요. 입력한 단어는 이 브라우저 밖으로 나가지 않습니다.

1. 단어 입력

인식된 단어 0개
구분은 -, :, =, 탭, 띄어쓰기 중 무엇이든 괜찮아요. 엑셀에서 두 열을 복사해 붙여넣어도 됩니다.
엑셀·CSV·TXT·PDF·사진(글자 인식) 지원 (입력창에 끌어다 놓아도 돼요)

불러온 단어 확인

뜻이 시작되는 위치
표제어와 뜻이 서로 섞여 읽히면 위 막대를 좌우로 움직여 보세요.
노란 줄의 ⚠는 글자가 잘못 읽혔을 가능성이 커요. 영어나 뜻을 눌러 바로 고칠 수 있습니다.

2. 시험 설정

시험 유형
문제 수 (최대 100)
직접 입력
뜻이 여러 개인 단어
예: bank - 은행, 둥 → 따로 출제하면 뜻 ①(은행), ②(둥)을 각각 다른 문제로 냅니다. 뜻은 쉼표, 세미콜론, 슬래시로 나뉘고, 괄호 안의 쉼표는 나누지 않아요.
시험 제목
학원 이름 (선택)
인쇄 창에서 대상을 PDF로 저장으로 고르면 파일로 저장돼요. 인쇄가 열리지 않으면 이 파일을 브라우저에서 직접 열어서 사용해 보세요.
재시험지 만들기

온라인으로 시험 보기

정답은 키보드로 입력하거나 마이크(음성 인식)로 말할 수 있어요. 객관식은 보기를 누르면 됩니다. 학생용 링크는 이 시험지를 그대로 열어주며, 링크에 정답이 포함돼 있어서 연습용·학원 내부용으로 쓰세요.
